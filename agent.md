# AGENTS.md

## Skills disponíveis

Este repositório usa instruções baseadas em *skills*.

### Lista de skills
- **skill-creator**: Guia para criar ou atualizar skills.
- **skill-installer**: Guia para instalar skills no `$CODEX_HOME/skills`.

## Como usar skills
1. **Descoberta**: verifique a lista de skills disponíveis na sessão.
2. **Ativação**: use uma skill quando ela for citada explicitamente ou quando a tarefa se encaixar claramente.
3. **Leitura mínima**: abra o `SKILL.md` e carregue apenas o necessário.
4. **Reuso**: prefira scripts/templates existentes em vez de recriar conteúdo.
5. **Contexto enxuto**: evite carregar arquivos desnecessários.
6. **Fallback**: se uma skill não estiver acessível, informe brevemente e siga com a melhor alternativa.

## Coordenação
- Quando mais de uma skill se aplicar, use o menor conjunto necessário.
- Informe rapidamente qual skill está sendo usada e por quê.
- Se não usar uma skill óbvia, explique em uma linha.
